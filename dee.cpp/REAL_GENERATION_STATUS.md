## Definitions

* **Tier-0.5**: component-level. Uses safetensors directly via
  `safetensors.torch.load_file`, picks one real Ornith expert, computes
  pure-torch SwiGLU FP32 reference, calls `pydee.Engine.moe_forward_experts`
  for the SAME expert, compares. Bypasses HF forward path entirely.
* **Tier-1**: end-to-end HF forward. Tokenizer → embed → N×(decoder_layer)
  → LM head → greedy. DeeMoeAdapter monkey-patches each layer's MLP.
  Needs HF modeling code for `qwen3_5_moe_text`. Currently blocked.
* **Tier-0.6 (planned, not built)**: amortised multi-expert tier-0.5 with
  one engine.init and N expert forwards. Catches per-expert numerical
  outliers and K>1 combined correctness.
